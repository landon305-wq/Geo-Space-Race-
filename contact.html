Reporting a wrong answer

If you think a question has a mistake, please include:

  • The game mode (Daily Challenge, USA, Europe, Global or Practice Mode) and the date if it was a daily mission
  • The question text, or as much of it as you remember
  • Which answer you think is wrong and a source that shows the correct answer

Suggesting a question

Have a great geography fact that would make a good mission? Send it in with a source, and it may be added to a future Daily Challenge.

Leaderboard problems

If you see an inappropriate name on a leaderboard or want your own entry removed, email us with the name and the leaderboard it appears on.

We usually reply within a few days.
